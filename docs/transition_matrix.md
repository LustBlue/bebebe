# Матрица переходов состояний задачи

Документ подготовлен по задаче 3.2 «Разработка тестовых наборов на основе моделей». Матрица построена автоматически из модели предметной области (`src/core/models.py`, объект `STATUS_TRANSITIONS`) генератором `tools/make_model_docs.py`, поэтому она всегда соответствует реализации.

## 1. Статусы жизненного цикла задачи

| Код | Название | Значение `tasks.status` |
|---|---|---|
| S1 | Новая | `new` |
| S2 | В работе | `in_progress` |
| S3 | На проверке | `review` |
| S4 | Завершена | `completed` |
| S5 | Отклонена | `rejected` |
| — | Удалена (терминальное) | запись удаляется из БД |

## 2. Матрица переходов

| Исходный статус \ Целевой | Новая | В работе | На проверке | Завершена | Отклонена |
|---|---|---|---|---|---|
| **Новая** (`new`) | — | **T1** | ✗ | ✗ | **T2** |
| **В работе** (`in_progress`) | ✗ | — | **T3** | ✗ | **T4** |
| **На проверке** (`review`) | ✗ | **T6** | — | **T5** | ✗ |
| **Завершена** (`completed`) | ✗ | **T8** | ✗ | — | ✗ |
| **Отклонена** (`rejected`) | **T7** | ✗ | ✗ | ✗ | — |

Обозначения: **T1–T8** — разрешённые переходы, ✗ — запрещённые переходы, — переход в то же состояние (не является операцией).

Всего состояний: 5; всего разрешённых переходов: 8; всего пар состояний: 25; запрещённых пар: 12.

## 3. Перечень переходов и допустимые роли

| № | Переход | Код в БД | Допустимые роли | Описание |
|---|---|---|---|---|
| T1 | Новая → В работе | `new` → `in_progress` | администратор, исполнитель, менеджер | Взять задачу в работу |
| T2 | Новая → Отклонена | `new` → `rejected` | администратор, менеджер | Отклонить некорректную задачу |
| T3 | В работе → На проверке | `in_progress` → `review` | администратор, исполнитель, менеджер | Отправить результат на проверку |
| T4 | В работе → Отклонена | `in_progress` → `rejected` | администратор, менеджер | Прекратить работу над задачей |
| T5 | На проверке → Завершена | `review` → `completed` | администратор, менеджер | Принять результат работы |
| T6 | На проверке → В работе | `review` → `in_progress` | администратор, менеджер | Вернуть задачу на доработку |
| T7 | Отклонена → Новая | `rejected` → `new` | администратор, менеджер | Вернуть отклонённую задачу в работу |
| T8 | Завершена → В работе | `completed` → `in_progress` | администратор, менеджер | Переоткрыть завершённую задачу (требует прав менеджера) |
| — | любой статус → Удалена | запись удаляется |  | Удаление задачи (запись удаляется из БД) |

## 5. Отрицательные сценарии (запрещённые переходы)

Проверяется, что реализация отклоняет переходы, отсутствующие в модели (тест `test_invalid_transitions_are_blocked` и `test_no_extra_transitions_in_implementation`).

| Переход | Обоснование запрета | Ожидаемый результат |
|---|---|---|
| Новая → Завершена | задача не может быть завершена без выполнения | `ValidationError`: «Невозможно перейти из статуса 'new' в 'completed'» |
| Новая → На проверке | нельзя отправить на проверку невыполненную задачу | `ValidationError`: «Невозможно перейти из статуса 'new' в 'review'» |
| В работе → Новая | задача не может вернуться в исходное состояние | `ValidationError`: «Невозможно перейти из статуса 'in_progress' в 'new'» |
| В работе → Завершена | результат должен пройти проверку | `ValidationError`: «Невозможно перейти из статуса 'in_progress' в 'completed'» |
| На проверке → Новая | задача не может вернуться в исходное состояние | `ValidationError`: «Невозможно перейти из статуса 'review' в 'new'» |
| На проверке → Отклонена | отклонение выполняется до передачи на проверку | `ValidationError`: «Невозможно перейти из статуса 'review' в 'rejected'» |
| Завершена → Новая | завершённая задача не может стать новой | `ValidationError`: «Невозможно перейти из статуса 'completed' в 'new'» |
| Завершена → На проверке | завершённая задача возвращается только в работу | `ValidationError`: «Невозможно перейти из статуса 'completed' в 'review'» |
| Отклонена → В работе | отклонённая задача возвращается только в новую | `ValidationError`: «Невозможно перейти из статуса 'rejected' в 'in_progress'» |
| Отклонена → Завершена | отклонённая задача не может быть завершена | `ValidationError`: «Невозможно перейти из статуса 'rejected' в 'completed'» |
