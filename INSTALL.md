# Установка и настройка ProjectFlow

Документ описывает подготовку рабочего окружения, запуск системы и
выполнение проверок. Для базового запуска внешние библиотеки не требуются:
система работает на стандартной библиотеке Python.

## 1. Требования к окружению

| Компонент | Требование | Примечание |
|---|---|---|
| Python | 3.10 и новее | проверено на 3.10, 3.11, 3.12 |
| СУБД | SQLite | входит в стандартную библиотеку Python |
| Операционная система | Windows, Linux, macOS | ограничений нет |
| Git | любая актуальная версия | для работы с репозиторием |

## 2. Получение исходного кода

```bash
git clone <адрес-репозитория> ProjectFlow
cd ProjectFlow
```

## 3. Базовый запуск (без внешних зависимостей)

```bash
# Создать схему базы данных
python run.py --init-db

# Запустить сервер (по умолчанию 0.0.0.0:5000)
python run.py

# Либо с указанием адреса и порта
python run.py --host 127.0.0.1 --port 8080
python -m src --host 127.0.0.1 --port 8080
```

Признак успешного запуска — ответ `{"status": "ok"}` на запрос
`GET http://127.0.0.1:5000/api/health`.

## 4. Демонстрационные данные

```bash
python run.py --demo-data
```

Команда создаёт (если их ещё нет) пользователей `admin`, `manager`,
`executor`, два проекта и пять задач в различных состояниях. Пароли
приведены в [QUICK_START.md](QUICK_START.md).

## 5. Дополнительные возможности (внешние зависимости)

| Возможность | Библиотека | Команда установки |
|---|---|---|
| Экспорт отчётов в Excel | `openpyxl` | `pip install openpyxl` |
| Запуск тестов через pytest | `pytest`, `pytest-cov` | `pip install pytest pytest-cov` |
| Статический анализ (внешний) | `flake8`, `pylint` | `pip install flake8 pylint` |
| Сборка отчёта о практике | `python-docx`, `Pillow`, `openpyxl` | `pip install -r requirements.txt` |

Полный перечень зависимостей приведён в файле `requirements.txt`.
Если установка внешних библиотек невозможна, ограничьтесь базовым запуском и
встроенными инструментами проекта: экспорт в PDF, тесты, статический анализ,
генерация диаграмм и документов работают без них (для сборки DOCX требуется
`python-docx`).

## 6. Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `DATABASE_PATH` | путь к файлу базы данных | `projectflow.db` |
| `HOST` | адрес прослушивания | `0.0.0.0` |
| `PORT` | порт сервера | `5000` |
| `DEBUG` | подробный вывод и трассировки | `False` |
| `JWT_SECRET_KEY` | ключ подписи токенов | значение для разработки |
| `JWT_ACCESS_TOKEN_EXPIRES` | срок действия access-токена, с | `3600` |
| `JWT_REFRESH_TOKEN_EXPIRES` | срок действия refresh-токена, с | `604800` |
| `REPORTS_DIR` | каталог для сформированных отчётов | `./reports` |
| `APP_NAME`, `APP_VERSION` | идентификация приложения | `ProjectFlow`, `1.0.0` |

Пример настройки приведён в файле `.env.example`.

> **Важно.** Значение `JWT_SECRET_KEY` обязательно следует заменить при
> развёртывании: ключ, заданный по умолчанию, предназначен только для
> разработки и тестирования.

## 7. Проверка установки

```bash
# 1. Схема базы данных
python run.py --init-db

# 2. Автоматические тесты (встроенный запускающий модуль)
python -m tools.run_tests

# 3. Статический анализ кода
python tools/inspect_code.py

# 4. Проверка соответствия реализации математической модели
python tools/make_model_docs.py

# 5. Проверка конфигурации конвейера CI
python tools/verify_ci.py
```

Все команды должны завершаться успешно (код возврата 0).

## 8. Возможные затруднения

**`ModuleNotFoundError: No module named 'src'`**
Запускайте команды из корневого каталога проекта либо используйте
`python run.py`, который сам добавляет корень проекта в путь поиска модулей.

**Порт 5000 занят**
Укажите другой порт: `python run.py --port 8080`.

**Файл базы данных заблокирован (Windows)**
Остановите предыдущий экземпляр сервера: файлы `projectflow.db-wal` и
`projectflow.db-shm` удерживаются процессом. После остановки сервера
соединение закрывается автоматически.

**Устаревшая схема базы данных**
При запуске выполняется автоматическая миграция схемы (в частности,
переименование устаревшего столбца `tasks.assignee_id` в `tasks.assigned_to`).
Для полного пересоздания удалите файл `projectflow.db` и выполните
`python run.py --init-db`.

**Экспорт в Excel не работает**
Установите `openpyxl`: `pip install openpyxl`. Экспорт в PDF не требует
внешних библиотек.
