# ProjectFlow - Информационная система управления проектами

## Описание проекта

ProjectFlow - это комплексная система управления проектами, разработанная в рамках производственной практики ПП.02. Система включает три основных модуля:

- **AuthModule** - модуль авторизации и управления пользователями
- **TaskModule** - модуль управления задачами и проектами
- **ReportModule** - модуль формирования отчётов

## Архитектура системы

Система построена на базе Python 3.10+ с использованием:
- Flask - веб-фреймворк
- SQLAlchemy - ORM для работы с базой данных
- JWT - аутентификация на основе токенов
- PostgreSQL/SQLite - система управления базами данных
- pytest - фреймворк для тестирования

## Установка и запуск

### Требования
- Python 3.10+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Инициализация базы данных

```bash
python src/core/database.py
```

### Запуск приложения

```bash
python src/main.py
```

Приложение будет доступно по адресу: http://localhost:5000

## API Endpoints

### Модуль авторизации (AuthModule)
- `POST /api/auth/register` - регистрация пользователя
- `POST /api/auth/login` - вход в систему
- `POST /api/auth/logout` - выход из системы
- `POST /api/auth/refresh` - обновление токена
- `POST /api/auth/reset-password` - восстановление пароля

### Модуль задач (TaskModule)
- `GET /api/tasks` - получить список задач
- `POST /api/tasks` - создать задачу
- `GET /api/tasks/{id}` - получить задачу по ID
- `PUT /api/tasks/{id}` - обновить задачу
- `DELETE /api/tasks/{id}` - удалить задачу
- `PATCH /api/tasks/{id}/status` - изменить статус задачи
- `PATCH /api/tasks/{id}/assign` - назначить исполнителя

### Модуль отчётов (ReportModule)
- `GET /api/reports/by-user/{user_id}` - отчёт по исполнителю
- `GET /api/reports/by-project/{project_id}` - отчёт по проекту
- `GET /api/reports/by-period` - отчёт за период
- `GET /api/reports/export/pdf` - экспорт в PDF
- `GET /api/reports/export/excel` - экспорт в Excel

## Тестирование

Запуск всех тестов:
```bash
pytest
```

Запуск с покрытием:
```bash
pytest --cov=src --cov-report=html
```

## Роли пользователей

1. **Администратор** - полный доступ ко всем функциям системы
2. **Менеджер** - управление проектами и задачами, просмотр отчётов
3. **Исполнитель** - работа с назначенными задачами
